## What the notebook does
1. Missing values for every column
2. Descriptive statistics: min, max, mean, median, mode, Q1, Q3, P90, P99, std, skewness, kurtosis
3. Histogram for each numerical variable
4. Boxplot for each feature and IQR outliers
5. Z-score of MonthlyIncome and |z| > 3 outliers
6. Normality of MonthlyIncome, Age and TotalWorkingYears: Shapiro–Wilk, histogram with normal curve, Q–Q plot

## Data
`data/HR_Analytics_data.csv` · 1,470 employees × 36 columns, including the `Attrition` target.
